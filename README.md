# claude-video-editor

ben's video studio for Claude: styles, custom skills, and reusable templates for making videos with
[HyperFrames](https://github.com/heygen-com/hyperframes) (open source, renders HTML to video).

- `styles/` one folder per visual style (`frame.md`)
- `.claude/skills/` ben's own video skills
- `templates/` finished videos to start from
- `projects/` work in progress
- `setup/cloud-setup.sh` paste into the project's cloud environment setup script

See `CLAUDE.md` for how Claude works here.
